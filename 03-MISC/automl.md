## ☁️ Cloud AutoML Platforms

| **Tool**                            | **Developer / Provider** | **Key Features**                                                 | **Notes / Use Cases**                                                   |
| ----------------------------------- | ------------------------ | ---------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **Google Cloud AutoML / Vertex AI** | Google                   | Supports tabular, vision, text, and forecasting models           | Fully managed, integrates with BigQuery and other Google Cloud services |
| **Azure AutoML**                    | Microsoft                | Automated model selection, hyperparameter tuning, explainability | Integrated into Azure ML Studio, supports Python SDK                    |
| **AWS SageMaker Autopilot**         | Amazon                   | End-to-end AutoML including data prep, training, and deployment  | Works with AWS S3 and SageMaker pipelines                               |
| **IBM AutoAI (Watson Studio)**      | IBM                      | Auto data prep, model selection, hyperparameter optimization     | Enterprise-focused, explainable ML models                               |
| **Databricks AutoML**               | Databricks               | AutoML for tabular data in Spark environment                     | Integrated with MLflow, supports Python and SQL                         |
| **DataRobot (Cloud)**               | DataRobot                | Enterprise-grade AutoML platform                                 | Strong focus on deployment and governance                               |
| **H2O Driverless AI (Cloud)**       | H2O.ai                   | Cloud version of H2O’s commercial AutoML                         | Includes advanced feature engineering and model interpretability        |

## 🧩 Open-Source AutoML Libraries

| **Tool**                     | **Developer / Provider**          | **Key Features**                             | **Notes / Use Cases**                        |
| ---------------------------- | --------------------------------- | -------------------------------------------- | -------------------------------------------- |
| **Auto-sklearn**             | University of Freiburg            | Built on scikit-learn, Bayesian optimization | Great for classical ML problems              |
| **TPOT**                     | University of Pennsylvania        | Genetic programming to evolve ML pipelines   | Optimizes pipeline structure automatically   |
| **H2O AutoML (Open Source)** | H2O.ai                            | Supports GLM, GBM, XGBoost, Deep Learning    | Scales well, used in production environments |
| **AutoKeras**                | Texas A&M University / Keras Team | Deep learning–focused AutoML built on Keras  | Great for image/text classification          |
| **PyCaret**                  | Community-driven                  | Low-code ML automation                       | Ideal for quick experimentation              |
| **MLJar Supervised**         | MLJAR                             | End-to-end AutoML with reports               | Emphasizes model transparency                |
| **FLAML**                    | Microsoft Research                | Lightweight AutoML, cost-efficient           | Fast and easy to integrate into workflows    |
| **Ludwig**                   | Predibase / Uber                  | Declarative ML with config files             | Useful for structured, text, and image data  |
